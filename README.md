# 광주·전남 학교공간지도 v1.5

만든이: **히스토리아쌤(광주역사교사모임)**

학교 위치와 학교알리미의 2026년도 체육장(운동장)·체육관·강당 개방 공시를 함께 살펴보는 독립 제작 지도입니다. 공시상 ‘개방’은 현재 예약·이용 가능을 보증하지 않으므로 실제 이용 조건은 학교에 확인해 주세요.

- 자료 출처·기준일·원작 표기: [`sources.html`](sources.html), [`데이터_출처_기준.md`](데이터_출처_기준.md)
- 학교 명부: 2026년 10월 조회·대조한 1,207개교. 2026년 5월 동결본과 동일하다고 주장하지 않습니다.
- 체육관·강당·체육집회공간의 실제 동일성은 미확인으로 남겨 서로 합산하지 않습니다.

공개 페이지에는 화면 동작에 필요한 가공 데이터만 넣었습니다. 학교알리미에서 내려받은 원본 파일, 내부 검증 파일, 원작 사용 허락 증빙은 포함하지 않았습니다. 이 저장소를 기존 진학지도와 분리하여 운영합니다.
